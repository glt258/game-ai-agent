# Architecture Decisions

本目录保存 Engineering Knowledge Layer 维护的少量、可审查的架构决策记录。

ADR 规范：

- 文件名使用 `ADR-NNN-short-title.md`。
- 每个 ADR 必须说明状态、决策、背景、后果和证据路径。
- ADR 记录工程事实与取舍，不复制运行时契约正文。
- 被替代的 ADR 保留原文件，并使用 `supersedes` 或 `deprecated_by` 表达关系。
- 历史 release report 不会自动转换为 ADR。
