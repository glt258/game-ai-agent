## SLOT-01 — 唐栖

### Basic

- Age: 22
- Legal Age Status: adult
- Gender: female
- Phenotype: baseline_humanoid
- Current City: 临洲市
- Life Identity: 刚取得正式资格的城市协理事务所助理协理人；主要处理小型委托的预约、现场记录与后续跟进
- Gameplay Rarity: A

### Naming

- Display Name: 唐栖
- Legal / Native Name: 唐栖
- Localized Name: Tang Qi；按普通话拼音转写
- Public Alias / Stage Name: 无
- Naming Strategy: natural_naming + family_background
- Reference: none
- Source: n/a
- Element Used: n/a
- Transformation: n/a
- Naming Logic: “栖”来自家人希望她不要只顾着往前赶，也能在城市里找到可停留的地方。名字自然、短、易读，但不会直接泄露能力或剧情。

### Character Sell

- One-line Pitch: 工作上极可靠，私生活却像一张没有归档的桌面。
- First Impression: 她会在客户说完第一句话前就打开记录本，确认时间、地点、谁已经同意了什么；下班后却会站在便利店门口翻遍三个包，找不到刚买的东西。
- Visual / Behavioral Motif: 她总在移动中完成记录，手指沿着路线点到哪里，视线就跟到哪里；面对自己的房间时却会把待办便签贴成互相遮挡的一团。
- Memorable Contrast: 她能记得客户合同的截止日，却连续三个月忘记给自己的出租屋更换漏水的水龙头垫圈。
- Why Players Remember Them: 她是最贴近日常工作的入口角色：玩家能看见“推进一件事”如何变成具体的路线、回访和责任，而不是抽象的信息能力。
- Why A / Why S: A 代表稳定、清晰且可持续的生活型产品位；她的价值在于高频日常场景和可靠的视觉动作，不依靠稀有感或世界观权限制造吸引力。

### Visual Direction

- Silhouette: 轻便短外套、窄肩斜挎包、可折叠文件夹和一条总是绕在腕上的门禁绳；站姿前倾，像随时准备去下一个地点。
- Wardrobe: 低饱和工作便服，衬衫与运动鞋混搭；衣物有细小但明显的修补痕迹，说明她没有把“体面”理解成昂贵。
- Key Props: 夹板、便签贴、两把长得很像的钥匙、未拆封的水管胶带。
- Motion / Gesture Motif: 先用手指沿地图或地面路线点出下一步，再回头确认所有人是否跟上；焦虑时会把物品按“马上要用 / 之后再说”分成两堆。
- Phenotype Visual Notes: 基准人形，不用身体特征替代人物识别。
- Color / Shape Direction: 纸张白、旧砖灰和一块偏亮的橙色路线标记；构图强调线段、折角、方向箭头，不使用元素属性语言。

### Life

- Daily Routine: 早上骑共享单车到事务所，先整理前一天的回访；上午处理预约和交通路线；下午随资深协理人跑现场；晚上在出租屋把当天的便签重新抄成电子清单。
- Current Concerns: 第一次独立接案是否会漏掉责任边界；合租房押金争议；母亲认为她“太早把自己变成一个工作的人”；想买一台二手洗衣机但还在比较维修成本。
- Hobbies: 研究城市公交换乘；在二手市场买小型收纳工具；把便利店新品按“适合通勤 / 适合加班”做私人评分。
- Family / Social Situation: 与父母住在临洲外围时关系亲近但联系频率不高；有一位大学同学仍在读书，常把她当免费搬家顾问；在事务所受到一位资深协理人的严格照看。
- Money / Consumption Detail: 对订阅服务极度谨慎，却会为“能减少每天三分钟麻烦”的小工具冲动消费；月底常发现自己买了重复的充电线。

### Personality

- Surface: 反应快、讲流程、愿意先把麻烦接过来。
- Underlying: 她真正害怕的不是失败，而是别人因为她的疏忽被迫承担无法申诉的后果。
- Values: 清楚的责任边界；承诺后的持续跟进；让当事人拥有知情和反悔的机会。
- Contradiction: 她尊重每个人的选择，却会用“我先替你安排好”来规避面对混乱的恐惧。
- Dislikes: 没有记录的口头承诺；把迟到解释成“大家都习惯了”；别人未经允许整理她的私人房间。
- Bad Habit: 遇到自己的问题就先建立表格，迟迟不做真正需要开口的沟通。

### Individual Bias

- Design-only Working Name: 接序
- Rule: 当她亲自走通并确认一组现实节点的先后关系时，A → B → C → D 这样的行动链在短时间内更不容易在执行中断裂。
- Trigger: 她必须亲自到达每个节点，并明确确认“完成这一节点后，下一步由谁做什么”；只看地图或替别人规划不算触发。
- Limitation: 只作用于已经走通的短链条；不能制造节点、改变建筑结构、让人服从或保证最终结果。任何一个节点的前提被改变，后续链条会从该处开始失稳。
- Daily Use: 按顺序完成搬家、取件、缴费和维修预约；她会把复杂家务拆成几个能逐项勾掉的节点。
- School / Professional / Contextual Use: 在协理现场把客户、场地方和后续办理地点串成可执行的行动链；她减少的是“做到一半才发现下一步没人接手”，不是替人调查事实。
- Danger Scene Use: 为撤离、急救交接和现场封控建立连续节点；前一节点完成后，下一节点的标记短暂稳定，帮助队伍不在交接处断掉。
- Visual Manifestation: 多个橙色节点依次亮起，前一节点完成后才把细折线接到下一节点；已经完成的节点变成实心方块，未完成节点保持空心，不形成一条宽阔地面通道。
- Risk / Failure: 节点顺序判断错误会让整条行动链在错误处变得更难改道；连续使用会让她强迫性重做前置步骤，甚至拒绝承认现场已经变化。
- Why this reflects self-conception: 她把自己理解成“让事情在交接处不断掉的人”，偏置强化的是顺序和接续，而不是净空、导航或信息处理。

### Combat Concept

- Tentative Role: flex / control
- Combat Fantasy: 画出路线、制造短暂可行的移动顺序，让队伍在城市障碍中持续前进。
- 3-second Gameplay Visual: 她依次拍亮三个橙色节点：确认伤员、交接担架、打开出口；第一节点变成实心方块后，第二节点才接上线，队友在“下一步”亮起的瞬间完成交接。画面重点是行动顺序没有断，不是地面生成通道。
- Why They Can Participate: 她是受训协理人，危险场景通常来自合法委托、撤离协作或公共安全转介；她负责开路与联络，不承担单人清场。
- Explicitly NOT: 不是发现证据、整理记忆、万能导航，也不是瞬移或空间传送。

### Narrative

- Personal Theme: 继续前进不等于永远不能停下。
- Personal Conflict: 她想证明自己足够可靠，于是把所有问题都变成路线管理，回避了需要亲自表达的私人关系。
- Possible Story Entry: 一起看似简单的商铺漏水委托，因为房东、租客、维修队和保险条款各自只走了一半流程而反复失败；唐栖第一次必须承认“没有一条路线能替人做决定”。
- Relationship to Main Conflict: 间接；她观察到机构把人分配进预设流程后，流程会反过来塑造人们对自己的理解。
- Potential Relationship With Player: 协理事务所同事 / 委托转介者；她会给玩家一张写满路线的便签，但不替玩家决定采取哪条方案。

### Agent Voice Seed

- Speech Rhythm: 语速中快，句子短，喜欢先报结论再补条件。
- Information Habit: 会把“已确认 / 待确认 / 不能确认”分开说；不喜欢用模糊的“应该没事”。
- Uncertainty Behavior: 不确定时会提出两个可执行选项，并明确说自己缺哪一条信息。
- Sensitive Topic: 被说成“只会跑腿”或“年轻所以可以随便改她的安排”。

### Design Risk Check

- Biggest cliché risk: 年轻可靠职场新人变成万能前辈或主角导师。
- Existing-character similarity risk: 路线可视化容易滑向导航类超能力或侦探能力。
- How this concept avoids it: 把能力锁定在亲自完成的节点顺序和行动接续上；她的生活缺口、私人回避和低权限职业身份持续存在，视觉上不使用净空带或宽阔通道。
- External name collision check recommended: yes

## SLOT-02 — Lumi（露米）

### Basic

- Age: 16
- Legal Age Status: minor
- Gender: female
- Phenotype: partial_theriomorphic
- Current City: 临洲市
- Life Identity: 槐庭区普通中学生，校内美术社成员；不是职业战斗人员、实验体或秘密组织成员
- Gameplay Rarity: S

### Naming

- Display Name: Lumi（露米）
- Legal / Native Name: 林露米
- Localized Name: Lumi；由“露米”这一家庭昵称转成的罗马字显示形式，并非外籍身份标签
- Public Alias / Stage Name: 美术社里有人叫她“胶带王”，她本人不喜欢这个称呼
- Naming Strategy: nickname_evolution + sound_design + natural_naming
- Reference: none
- Source: n/a
- Element Used: n/a
- Transformation: n/a
- Naming Logic: 命名复核后保留“林露米”：露米是父母共同选定的中文双字名，家人从幼儿园时期就这样叫她；她后来把同一昵称转成 Lumi，作为社交媒体和 UI 显示名。短、好记、有跨语言显示层，但不把她写成“外国人角色”或“中文姓氏加洋名”。

### Character Sell

- One-line Pitch: 她总在问“这是我的边界吗”，然后把别人的东西放回原位。
- First Impression: 个子不高、耳尾兽征明显，书包上贴着自己剪的警示贴纸；她第一次见面就会指出别人站得太近，但也会默默把走廊上挡路的纸箱搬到墙边。
- Visual / Behavioral Motif: 她一旦进入陌生空间就先找墙角、门口和可贴胶带的平面；确认安全后才把尾巴从腿边放开。
- Memorable Contrast: 她非常抗拒成年人替她做决定，却在家人加班时主动给弟弟准备晚餐并检查作业。
- Why Players Remember Them: 可爱外形与清晰自我判断并存；她不是“被保护的小动物”，而是一个会判断什么时候坚持、什么时候求助的中学生。
- Why A / Why S: S 的商业价值来自鲜明兽征、边界可视化和高识别度动作；稀有度不是因为能力更强，而是因为她能成为讨论“别人如何定义我”的核心角色。

### Visual Direction

- Silhouette: 大号校服外套、短裙或宽腿校服裤、蓬松耳尾、透明文件袋和卷成筒的彩色胶带；轮廓像一个随时能把私人空间围出来的小展台。
- Wardrobe: 普通学校制服为主，外加自己改过的袖口、护腕和帆布鞋；不使用战斗服或实验服。
- Key Props: 可撕警示胶带、折叠尺、社团钥匙、贴满修改痕迹的习题册。
- Motion / Gesture Motif: 先用胶带在地上或桌面标出一块区域，再站到边线上观察；承认需要帮助时会把胶带递给别人而不是自己继续贴。
- Phenotype Visual Notes: partial_theriomorphic；耳朵会因噪音和压力改变朝向，尾部是自然身体特征，不赋予额外物种能力。
- Color / Shape Direction: 奶白校服、酸柑黄胶带、深紫文字贴纸；视觉核心是封闭四边形与被故意留下的开口。

### Life

- Daily Routine: 早上和家人轮流使用浴室；上学后参加美术社；午休在图书馆靠窗的位置吃饭；放学先去文具店再回家；晚上和弟弟轮流使用书桌。
- Current Concerns: 美术社展览是否要接受商业赞助；数学成绩拖后腿；班主任希望她参加公开演示而她不想被当成“兽征代表”；家里近期要不要搬到更小的房子。
- Hobbies: 做手账贴纸；收集不同粘性和撕裂声音的胶带；看装修和收纳视频；给同学画“不侵犯隐私的”头像。
- Family / Social Situation: 与母亲、继父和年幼弟弟共同生活；家人支持她，但大人常把她的坚决误解成需要纠正的叛逆；在班级中有两位能互相吐槽的朋友。
- Money / Consumption Detail: 零花钱大多花在文具和限定胶带上；她会为了便宜五元走两站路，却愿意为社团公共材料先垫钱。

### Personality

- Surface: 直接、警觉、会当场说“不行”。
- Underlying: 她很怕自己的拒绝会让别人失望，所以会在冲突后反复确认“你是不是还生气”。
- Values: 自己说出口的同意；私人空间；把求助看成合作而不是失败。
- Contradiction: 她反对成年人替她判断，却经常替家人预先安排情绪和时间。
- Dislikes: 未经允许翻她的东西；“你还小不懂”式终止对话；把兽征当成可爱装饰拍照。
- Bad Habit: 一旦觉得界线被碰到就立刻封闭整个区域，事后才发现自己把真正愿意帮忙的人也挡在外面。

### Individual Bias

- Design-only Working Name: 贴界
- Rule: 当她亲手明确划出一块属于某人或某用途的区域，并让相关者理解其边界时，区域内外的物品与行动更难无意间越界。
- Trigger: 必须由她亲手完成可见标记，并说清“这里放什么 / 谁可以进 / 什么时候结束”中的至少两项；模糊的占有宣言无效。
- Limitation: 不能阻止有意破坏边界的人，不能凭空封锁空间，也不能判断谁在道德上正确；边界越大、参与者越多，维持时间越短。
- Daily Use: 整理社团材料、保护弟弟的作业区、让公共桌面保持“待处理 / 已完成”两块；也能帮助自己在嘈杂空间集中。
- School / Professional / Contextual Use: 在美术社布展时管理作品、工具和观众路线；在家庭冲突中把“现在先不谈”具体化成可回到的时间和位置。
- Danger Scene Use: 为撤离点、临时救护区或危险碎片周围划出清晰边线，减少无意踩入和物品被误拿；成年人负责实际安全处置。
- Visual Manifestation: 胶带边缘像被压实一样清晰，区域内的物件会短暂出现统一朝向；越界物体会被一条细线勾住并停顿。
- Risk / Failure: 她在压力下会不断扩大禁入区，导致队友无法协作；若界线没有得到相关者理解，效果会快速剥落。
- Why this reflects self-conception: 她把“我是谁”理解为“我允许什么进入我的生活”，能力表现是边界协商的现实化，不是魔法屏障。

### Combat Concept

- Tentative Role: control / defense
- Combat Fantasy: 用可见边界把混乱分区，让危险物、队友和可交互物各自保持清楚位置。
- 3-second Gameplay Visual: Lumi 撕下一段荧黄胶带贴地，四角亮起；冲来的杂物在边线前停顿半拍，队友从预留的开口撤出。
- Why They Can Participate: 她通常参与学校、家庭或社区事件的保护与撤离；危险场景需要成年协理人、教师或公共安全人员在场，不能把她当作前线雇员。
- Explicitly NOT: 不是领域展开、空间封锁、绝对防御或兽类本能技能。

### Narrative

- Personal Theme: 边界不是把所有人挡在外面，而是让关系可以安全地继续。
- Personal Conflict: 她想被当作有判断力的人，又害怕承担“判断错了会伤害别人”的责任。
