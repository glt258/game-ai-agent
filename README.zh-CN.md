# Game AI Agent

**AI 辅助游戏设计与开发框架**

本仓库提供结构化游戏内容创作、校验与评估的软件公开演示版本。

## 本公开版本的边界

打包数据仅包含合成演示记录，不包含原项目世界观、正式剧情 Canon、正式角色阵容或第三方角色参考语料。示例数据刻意保持精简，不代表一套完整游戏世界观。

## 能力范围

- 结构化角色与技能创作工作流。
- 有界检索与确定性校验接口。
- 模型 Provider 适配器及可审计调用边界。
- 实验性的 Web 工具与角色保存工作流。
- 离线战斗设计和评估原型。

模型输出只是供人审查的提案，不代表已获批准，也不会自动写入 Canon。实验结果不代表系统已达到生产就绪状态，也不构成对模型质量的普遍性结论。

## 开发

需要 Python 3.10 或更高版本。

```bash
python -m pip install -e ".[dev]"
game-ai-agent doctor
pytest
```

部分实验工作流需要通过环境变量配置 Provider 凭据。不要提交密钥或本机配置文件。

`src/along_street_resources/data/` 下仅保留合成示例。本仓库未声明许可证；不能仅凭源码公开就推定获得了复用授权。
